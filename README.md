# 2027 生涯探索年历 · 网页版站点

闽幼高专社团生涯教育课程配套工具。全年 365 天，每天一个可单独完成、又能按周与季串联的生涯探索动作；按专科三年与五条走向（A 升学 / B 就业 / C 创业 / D 考编 / E 参军）给出变体；24 个专业各有专属探索日，落在真实节日与节气上。

## 一、怎么打开

双击 `index.html` 即可在任意浏览器离线打开，不需要联网、不需要安装任何东西。索引页分别通向全年页、四季页、月份页与 24 个专业页。

| 文件 | 页数 | 用途 |
|---|---|---|
| `index.html` | 1 | 站点入口：全年 / 四季 / 12 个月 / 24 专业的索引卡与使用说明 |
| `year.html` | 1 | 全年 365 天总览，含筛选与搜索 |
| `q1.html`—`q4.html` | 4 | 分季度（1—3 月、4—6 月、7—9 月、10—12 月） |
| `m01.html`—`m12.html` | 12 | 按月出页，适合直接打印当月日卡 |
| `major_<专业名>.html` | 24 | 单个专业的专属探索日：为什么是这天、当日动作、材料、产出、配套工具卡 |

全部页面共 42 个，每个都是单文件，CSS / JS / 配图（内联 SVG）全部写在文件内部，零外链，可离线、可拷进 U 盘、可挂内网。

## 二、页面怎么用

1. **全年页**用于整体备课与班会排期：先看日类型色带（锚定日、工具卡日、周闭环、节气观察、季度体检、月度成果、专业专属日、弹性日、归档日），再按月份细读。
2. **月份页**用于直接发班级：打印当月的日卡，贴公告栏或按周发放。
3. **专业页**用于专业专属日：建议由本专业班主任或社团带组者统一组织，45—60 分钟完成，产出收进学生生涯档案袋。
4. **筛选**：全年页、四季页顶部可按走向、月份、日类型、专业筛选，也可用关键词搜索（如"访谈""简历""专升本"）。
5. **展开细节**：点击任一卡片，可展开该日对应的工具卡步骤、变体说明与备注。

## 三、打印

浏览器 `Ctrl+P`。样式已内置 A5 纵向打印规则：卡片两栏排布、单卡不跨页断裂、左侧预留装订打孔位（打印时左侧出现竖排孔位刻度线）。

> 本次交付为网页版。A5 带配图与打孔位的成品打印版（PDF / 印刷稿）按计划在下一步制作，届时会在本版基础上加插图与版式微调。

## 四、内容口径（引用与宣讲时请照此说）

- 本工具是**探索框架**，不是测评、不产出结论、不替学生做选择。每天给一个动作，学生自己填空。
- **不承诺任何结果**：不涉及录取率、上岸率、薪资、编制、名额等承诺性表述。
- **不写薪资与编制类事实**：涉及待遇、编制、岗位数量的话题，只给"怎么查、去哪查、问谁"的动作，不给数字。
- 专业与学院信息以学校官网公布的在办专业为准（24 个专业，覆盖学前、艺术、人文、外语、信科五个学院）。
- 涉及招生、就业、资助等政策，一律以学校官方最新通知为准，本工具只做"提醒去核对"。
- 女生占比高、去向以幼儿园 / 早教托育 / 教培艺术机构为主，是内容取材语境，不作为对学生个体去路的判断。

## 六、改内容与重新生成

所有页面由 `2027生涯探索年历_data.json` 这一份数据生成，**不要直接手改 HTML**，改数据后重跑脚本即可全站同步。

```bash
# 在本目录内执行（Node v18+，本机已验证 v22.12.0）
node build_site.mjs

# 指定数据与输出目录
node build_site.mjs --data 2027生涯探索年历_data.json --out .
```

生成后会覆盖 42 个 HTML 页。改数据的典型场景：调整某天动作、增删工具卡、改某专业专属日的日期或题目。
